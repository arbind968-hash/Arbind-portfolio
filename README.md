# Arbind Portfolio - MERN Stack Application

A full-stack portfolio application built with MongoDB, Express.js, React, and Node.js.

## 🚀 Features

- **Modern Portfolio Design** - Dark/light theme, responsive layout
- **Project Showcase** - Dynamic project display with filtering
- **Contact System** - Smart form with email notifications
- **Admin Dashboard** - Manage projects and messages
- **Authentication** - JWT-based secure login
- **Database Integration** - MongoDB for data persistence
- **RESTful API** - Complete backend API
- **Performance Optimized** - Lazy loading, code splitting

## 📦 Tech Stack

### Frontend
- React 18 with Vite
- React Router v6
- Tailwind CSS
- Framer Motion
- Axios
- Lucide React Icons

### Backend
- Node.js
- Express.js
- MongoDB with Mongoose
- JWT Authentication
- Nodemailer
- Express Validator
